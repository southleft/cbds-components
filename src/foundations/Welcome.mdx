## Why this library looks the way it does

Three ideas, and where each one shows up here.

<div className="cbds-welcome__grid">
  <div className="cbds-welcome__card">
    <h3>Design to code, via AI</h3>
    <p>
      Nothing here was written from a screenshot. Each component was generated by pointing an
      assistant at a Figma component set that already stated its purpose, its behaviour, and its
      accessibility contract. The gap between a good result and a bad one is almost entirely the
      quality of what the design file had to say.
    </p>
  </div>
  <div className="cbds-welcome__card">
    <h3>Context is the product</h3>
    <p>
      A component set carrying only geometry gives a generator geometry. One that also says which
      states are pseudo-classes rather than props, and what must happen to focus on dismiss, gives
      you something you would merge. That is why <code>Chip</code> arrived already knowing its focus
      ring is <code>:focus-visible</code>.
    </p>
  </div>
  <div className="cbds-welcome__card">
    <h3>Somebody inherits this</h3>
    <p>
      A design system gets handed to a team that was not in the room. What they inherit here is a
      token file that names its own source, a build that fails loudly when code drifts from design,
      and a component tree ordered by dependency depth.
    </p>
  </div>
</div>

## Three themes, one token set

The `colour semantic` collection in Figma has three modes and all three ship. Switch with the
paintbrush in the toolbar.

## The pipeline

```
Figma variables ──► tokens/dtcg/tokens.tokens.json   (W3C DTCG, canonical)
Figma styles    ──► tokens/json/global.json           (elevation + text styles)
                              │  npm run tokens
                              ▼
                    src/styles/tokens.css             :root — light + primitives
                    src/styles/tokens.dark.css        [data-theme='dark']
                    src/styles/tokens.brutalist.css   [data-theme='brutalist']
```

446 tokens across six collections, each carrying the description written on the Figma variable.
`npm run tokens` also reports drift — any `--cbds-*` a component references that no design source
defines.
